# Horizon unified experience — superseded

Horizon was the pre-release name for the shared Codestra visual system. **Codestra Orbit V2 is now the sole design authority.**

Use:

- [`ORBIT-UNIFIED-EXPERIENCE-SYSTEM.md`](ORBIT-UNIFIED-EXPERIENCE-SYSTEM.md)
- [`ORBIT-AUTH-PAGE-SUITE-RULES.md`](ORBIT-AUTH-PAGE-SUITE-RULES.md)
- [`ORBIT-ADOPTION-MATRIX.md`](ORBIT-ADOPTION-MATRIX.md)
- `@codestra/intake-ui/orbit`
- `@codestra/intake-ui/orbit/styles`

The abandoned Horizon proposal does not authorize light mode, blue primary actions, gradients, glow, shadow-heavy cards, large radii, or product-specific action colors. Temporary Horizon package and class names resolve to Orbit compatibility styles only.

New repositories and pages must register in `orbit/suite.json`. No production deployment is authorized by this compatibility record.
