`api-reference.html` in this directory is generated by
`scripts/generate-api-reference.mjs` (run automatically before `dev`/`build`)
from `contracts/openapi/codestra-public.openapi.yaml` via `@redocly/cli
build-docs`. It is not committed -- run `pnpm --filter @codestra/developer-portal generate:api-reference`
to produce it locally.
